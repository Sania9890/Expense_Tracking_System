# Expense Management System

Created a full-stack **Expense Tracking Tool** combining `FastAPI` for robust backend API development and `Streamlit` for an interactive frontend. The application allows users to **log, categorize, and annotate daily expenses**, supporting full **SQL-based CRUD operations** using `SQLite`. Backend logic includes structured logging for traceability and comprehensive unit testing using `PyTest`, all maintained within the `PyCharm` environment. Real-time analytics dashboards were integrated using `Streamlit`, offering **visualizations of spending patterns**, category-wise breakdowns, and monthly summaries — delivering **actionable insights** through a clean and responsive UI.
